For Studios→

프로젝트는 이렇게 소개됩니다.

건축사사무소, 인테리어 스튜디오, 시공 업체의 실제 프로젝트를 소개합니다. 게시 전에는 반드시 업체의 확인을 받습니다.

  1. 소개 가능 여부 문의

    인상 깊게 본 프로젝트를 짚어 짧게 연락드리고, 소개해도 괜찮은지 먼저 여쭙니다.

  2. 사진과 기본 정보 받기

    업체가 정한 프로젝트의 사진과 지역·평형·공사 범위 같은 기본 정보를 받습니다. 보내주신 자료만 사용합니다.

  3. 카드뉴스 초안 작성

    확인된 내용으로 초안을 만들고, 모르는 부분은 추측하지 않고 업체에 여쭙니다.

  4. 업체 사실 확인

    완성본을 먼저 보내드리고 내용과 사진 표기를 확인받습니다.

  5. 게시와 태그

    @archi_penguin 피드에 게시하고 업체 계정을 태그합니다.

Editorial rules

  • 사진은 업체가 보내주신 것만 사용합니다.
  • 확인되지 않은 정보는 쓰지 않습니다.
  • "최고", "완벽한" 같은 과장 표현을 쓰지 않습니다.
  • 렌더링 이미지는 실제 사진과 구분해 표기합니다.
  • 게시 전 업체에 완성본을 먼저 보여드립니다.
